# Nova Vanguard — art brief (shared by every sprite)

Game: original vertical-scrolling space shooter for mobile (portrait). Sprites are drawn on a canvas over a dark navy starfield (#0e1433).

Style for EVERY image (keep identical across the set):
- Strict top-down view (camera looking straight down), centered, symmetric left/right.
- Glossy semi-realistic 3D render, like premium mobile shooter art: clean hard-surface panels, bevels, soft studio light from top-left, subtle rim light, emissive glowing parts.
- Fully TRANSPARENT background (PNG with alpha). No floor, no shadow plane, no stars, no frame, no text, no watermark.
- Object fills ~90% of the canvas, nothing cropped.
- Original designs only: do not copy any existing game, film or franchise.
- Player ships and drones point UP (nose at top). Enemies and bosses point DOWN (facing the player).

## UI icons v2 (files icon_*.png) — sci-fi military HUD style, replaces the old cartoon set
- Genre: space shooter / air force. Icons must feel like a fighter-jet cockpit HUD, NOT a casual or kids game: no cute faces, no candy colors, no rounded toy shapes.
- Look: angular hard-surface emblem, gunmetal / dark titanium body with beveled edges, glowing neon cyan (#38e1ff) energy lines and accents; gold (#ffc83d) only for rewards/premium; red (#ff5164) only for danger/attack.
- Front view, slight 3/4 tilt, crisp silhouette readable at 32x32 px, subtle outer neon glow, specular highlight from top-left.
- TRANSPARENT background, no button plate, no circle/hexagon frame behind the object, no text or letters, object fills ~85% of the canvas.
- Every icon in the set must share the same materials, glow color, line thickness and lighting.

## Pilot portraits (pilot_*.png)
- Head-and-shoulders bust in a sci-fi flight suit, glossy 3D game style, transparent background.

## Backgrounds (bg_*.jpg)
- Portrait 1024x1536, painted deep-space scene seen from straight above for a vertical scrolling shooter. No ships, no characters, no text, no UI.
- Keep the middle 70% fairly calm and dark so bullets and ships stay readable; detail and brighter nebula near the edges.
- Top and bottom edges must have similar density and color so the image can scroll continuously.
